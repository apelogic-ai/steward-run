## Remediation

The v0.1.1 candidate updates the digest-pinned Actions Runner from 2.334.0 to
2.336.0 and applies current Ubuntu package upgrades during the image build. The
standalone curl/libcurl4 packages and all unused Docker/containerd/runc tooling
are removed. Git retains the GnuTLS-backed libcurl package required by checkout.
The Node 24 Bookworm base already resolves to the current digest and remains
pinned.

A complete Trivy 0.72.0 all-severity scan of the local v0.1.1 candidate reports
zero of the ECR-critical CVEs and zero scanner- or CVSS-critical findings. No
unfixed critical risk acceptance is required. ECR must confirm the released
manifest before production approval or GitOps promotion.

## Separate production-path work

This image remediation does not claim a real Steward or Agent Sandbox E2E. That
requires the runtime node pool and AMI, deployed Steward control plane, GitOps
activation, production OIDC validation, real sandbox provisioning, byte-exact
I/O, and cleanup verification as a separate phase.
